# 🏟️ TSB — The Stadium Builder

> **Build Your Stadium. Build Your Legacy.**

Welcome to the official web portal for **TSB (The Stadium Builder)**. We build custom, high-quality, and professional-grade stadiums tailored specifically for teams, clubs, leagues, and tournaments in the **VRFS (Virtual Reality Football Simulator)** community.

---

## 🚀 Features

- **Custom VRFS Stadiums:** Built to match your team's unique branding, colors, and layout preferences.
- **Pro-Level Architecture:** Modern designs built to bring showcase venues and cup finals to life.
- **Fast Turnaround:** Quick delivery times to get your pitch match-ready without long delays.
- **Community Hub:** Integrated links for direct ordering, portfolio browsing, and Discord support.

---

## 🛠️ Built With

- **HTML5** — Semantic structure and web markup.
- **CSS3** — Modern dark-theme styling, flexbox layouts, and custom UI components.
- **FontAwesome** — Vector icon set for UI visual accents.
